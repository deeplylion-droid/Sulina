# Chez Sulina

Gioco cozy per PC a scene fisse ispirato a New Style Boutique: un café-bar di quartiere a Montmartre, senza timer né clienti impazienti.

Il documento di concept, con mock interattivi di facciata, interno e personaggio, è in `docs/concept.html` (aprilo nel browser): include la direzione grafica (2D illustrato con luci morbide, ispirato a Heartopia), lo shopping nel quartiere e la schermata PC.
